# QQ Agent 本地网页

来自 <https://kondius.cn/qq-agent/> 的公开网页副本，抓取日期为 2026-10-21（北京时间）。

双击 `start-local.cmd`，然后在浏览器打开 <http://127.0.0.1:4173/qq-agent/>。保留启动窗口，关闭窗口即可停止服务。也可以在此目录运行 `node serve.mjs`，需要 Node.js 20 或更新版本。

## 文件

- `qq-agent/`：下载的原始 HTML、CSS、JavaScript、字体、图片、音乐和站点自带离线数据。
- `snapshots/`：公开接口的数据快照，以及人设提示词正文。
- `serve.mjs`：仅监听本机的预览服务，将原接口地址映射到本地快照。
- `local-preview.js`：本地预览标识。
- `mirror-manifest.json`：原始下载地址、MIME、文件大小、SHA-256 和抓取失败记录。
- `tools/download.py`：公开 HTTP 下载脚本；默认复用已验证文件，使用 `--refresh` 重新抓取公开内容。依赖 Python 3.10+ 和系统 curl。

原始网页文件保持下载时的字节内容；预览服务在响应中加入本地标识，将意见墙图片的绝对地址改成本地地址，并把市场的软件包下载链接补为原站绝对地址。网页浏览和公开内容读取使用本地文件，不需要启动 QQ 机器人。

本地导航页签由真实标题与正文进行空间交接：旧标题缩入纵深、正文稍晚后撤；新标题从较大的近景归位，描述、工具栏与列表从后景跟进。三道透明门廊、细光边与透视线提供空间参照，章节标记留在底栏。内容交接时短暂隐藏正文与共享页脚，防止异步占位引起文字叠加或页脚跳入；顶栏和播放器保持稳定。正常切换约一秒半，系统减弱动态或强制颜色模式直接切换，低性能档缩短运动时长。实现位于 `tools/local-navigation.mjs`，材质源文件为 `qq-agent/lab/navigation-stage.css`，生成时内联到导航模块，同时用于实验派生文件和原站副本的本地响应；原始下载文件仍不变。

连续点击以最后选择为准，揭幕途中可重新合拢交接。导航触发的渲染使用共享队列，浏览器前进后退不增加历史记录；离开页面时清理舞台与动画，在途渲染恢复时按当前地址对齐，空闲页面的返回保留原滚动位置和内容状态。社区标题的普通入场动画与滚动倾斜缓动也随切页清理；原版对照首页初建的柔光、跑马带、卡片浮动和鼠标缓动由页面动画上下文回收，磁吸文字的全局监听随页解绑。

导航只给安全的内容容器和临时外层添加透视变换，不变换 `#view`、固定画布或滚动固定舞台的祖先。临时外层保留原节点、事件与布局角色，完成、重入或页面隐藏时恢复样式并拆除。导航接管首屏入场，原有首访动画和后续滚动编排继续使用自己的生命周期；没有新增库、全屏模糊或截图纹理。

## 范围

此副本包含首页、意见墙、雷霆语录、Skill 市场、插件市场、人设广场、致谢页及公开的管理/个人页界面。数据是抓取时的快照，不会自动更新。

服务器后端程序与数据库不属于公开网页文件，本次没有下载。登录、注册、发布、点赞、回复、上传与管理操作需要后端；本地预览服务会返回明确提示。Windows 安装包、插件/Skill 安装包及 GitHub、Bilibili 等外部链接保留在线地址，未批量下载软件包。

预览服务不向线上转发接口请求。请通过本地服务预览，直接双击 HTML 不是完整的启动方式。

## 本地动效实验 06：构图接力

打开 <http://127.0.0.1:4173/qq-agent/lab/>。原版仍在 <http://127.0.0.1:4173/qq-agent/>，便于直接对照。

实验入口为 `qq-agent/lab/index.html`。沿用原版字体、紫蓝薄荷配色、玻璃材质、流动背景、Three、Anime 和 Life。`generated/core.js` 和 `generated/pages.js` 由 `node tools/build-precision-lab.mjs` 从下载原件生成，首页动效改由 `choreography.js/css` 统一编排，社区页面仍用原有交互。原始下载文件未被修改，也没有上传或部署。

整页的编排如下：

- 首屏：两行大字沿同一轴线升起，滚动时放大构图从文字前穿过，接真实粒子镜头和稳定的色带。
- 数据：细线先横向展开，再打开成二维数据框；四张数字卡沿框架逐项展开，数字与进度条落定。
- 工具：日志窗口从顶栏向下展开，悬停大标题与各类调用条相伴；社区长列表仍可展开和收起。
- 工具到能力：`chapter-gateway.js/css` 用独立内容流中的两扇玻璃门打开巨型 CAPABILITIES 字，不增加固定滚动舞台。
- 能力：`capability-stage.js/css` 负责实体卡片的有序展开。桌面矩阵从叠放卡柜展开，窄屏两幕用逐卡纵向换位交接，文字保持不透明。仅这一段在空间允许时短暂固定，矮屏恢复竖排阅读。
- 部署：大标题与连续进度线相伴，四块步骤面板依次向下打开，留出稳定阅读区间。
- 理由：大号描边序号归位、细线延展与正文分层揭开，保留一段安静阅读的节奏。
- 收尾：深色整幅画面从中央细缝向两侧打开，后方两行巨字由大尺度构图归位，接下载、群二维码和页脚。

`atmosphere.js/css` 负责相邻章节的环境颜色交接，三层柔光保持空间位置，随着章节在紫、蓝与薄荷绿之间接力。主要段落过渡通过尺度、裁切、开合及实体遮挡完成，颜色变化作为辅助。所有章节仍由原生滚动控制，没有接管滚轮，也没有新增第三方依赖。

首页动效通过 GSAP matchMedia 与页面清理钩子管理；字体就绪、视口变化和长列表展开后会重新计算段落位置。减弱动态和低性能档使用可直接阅读的静态排版，八张能力卡全部竖排。Three 离屏暂停并隐藏，切页销毁几何、材质和渲染器，同时移除监听、计时器和观察器。窄屏使用 1800 个球面粒子、320 个星尘和最高 1.25 像素比。左下角可返回首屏；系统减弱动态设置变化时重新载入本地页，使原模块和新增编排使用一致偏好。后端写入功能仍受本地预览范围限制。

跑马带由实验自身统一管理循环、调速与滚动触发器，离屏暂停，切页时一起清理。文本每次从初始内容生成，视口变化不会反复翻倍；调速使用普通数值代理，避免回调把已经销毁的循环重新挂回动画队列。

实验入口关闭浏览器的自动滚动位置恢复，刷新时从首屏重新开始；显式的返回首屏仍平滑滚动。这样避免浏览器恢复旧位置与固定舞台初始化同时发生，造成段落位置计算偏移。

实验文档中的首页链接回到 `/qq-agent/lab/index.html`，保留原站的同文档导航。当前浏览标签记住实验入口，在社区页刷新后点首页也会回到实验版。点击「原版对照」会打开带 `original=1` 标记的独立原版标签，该标签使用自己的预览偏好。`generated/provenance.json` 记录源文件校验值和派生改动；修改原始下载版本后重新运行生成器，边界不匹配时会停止。

实现依据：[GSAP](https://gsap.com/docs/v3/)、[ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/)、[matchMedia](https://gsap.com/docs/v3/GSAP/gsap.matchMedia()/)。
