# 社区页面精简（2026-10-19）

按用户标注删除口令安装入口及方法、社区内重复的屏蔽名单页面。社区现在直接显示发布账号与发布扩展表单，保留网站链接、意见收集、验证码诊断和创作扩展。

## 删除与保留边界

- 删除口令输入、批量添加/校验/安装状态机与视图文件，以及全部专属样式、页签、事件和离页逻辑；不保留隐藏入口。
- 删除 POST /api/market/verify、market.client.verify 的默认服务与SDK公开面。社区不再获得安装、校验和名单API权限。
- 安装仅保留技能/插件市场的目录操作，POST /api/market/install 与 SDK install 改为 {id,kind}；旧 code 参数明确拒绝。默认服务重新获取当前目录，只允许唯一且已审核的条目，用服务端给出的下载引用内部校验类型与身份后再下载。上游协议的内部校验未改为公开口令功能。
- 目录安装继续使用选中的市场服务及共享 ZIP 安装器，安装身份来自包内清单，新安装仍强制停用。未新增权限或旁路安装器。
- 删除社区名单表单、读取/保存/冲突处理/清空及其样式；聊天设置里的群成员、全局名单编辑和底层云同步、运行时拦截保留。共用 community.client 和兼容HTTP接口未因删页面被移除。
- 发布成功不再展示安装口令；账号登录/注册、退出、验证码、发布取消等待与反馈草稿保持原链路。
