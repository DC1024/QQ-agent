# 表情库与独立扩展能力

默认 OneBot 适配器不提供 QQ 收藏表情同步或账号侧收藏写入。本地已有表情索引、备注及读取能力保留；它们不证明 QQ 账号侧已经完成收藏或修改。

相关同步和收藏能力可由用户安装的独立扩展提供，支持情况由扩展决定。宿主通过明确的能力接口调用它们；缺少能力、权限不足、取消或外部失败时，应返回真实状态，不把缓存结果报告为远端成功。

扩展应遵循当前 SDK 的权限、取消、生命周期和配置代际约定。读取部分结果不表示完整收藏快照，不能据此删除未出现的本地记录；外部动作完成后取消也不代表已撤销远端效果。

开发接口见 [插件 SDK](plugin-sdk.md) 和 [扩展完整参考](extension-reference.md)。历史同步实现和测试结果不适用于当前默认适配器；安装扩展后仍需独立验证真实账号和协议端行为。
