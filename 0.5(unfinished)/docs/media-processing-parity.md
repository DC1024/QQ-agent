捆绑media-service默认reader现在只按上限缩小。图片上限1568、GIF首帧768、视频480；视频输出向下取偶数，极小或极细输入为了编码器仅保留2像素的必要下限。GIF仍至多24帧/8MB，原生视频仍20MB，首帧与抽帧仍4MB，下载与私网/路径/来源控制不变。

实际输出对照：64×48 GIF由480×360恢复为64×48；128×96视频原生输出由480×360恢复为128×96，抽帧由1568×1176恢复为128×96；512×384压缩图片不再放大至1568×1176。大图/大视频仍按原上限缩小。1×1 GIF视频以2×2编码，首帧保留1×1，奇数GIF可成功编码。
