# 多口令安装：0.4原子交互迁移

来源为旧`ui/app/09-community.js:764-872`的openInstallCodeModal；Code指分享口令，不是JavaScript源码。复用现有POST/market/verify、POST/market/install和默认市场/ZIP安装器，没有新增源码执行入口、RPC方法或权限。

## 迁移与改良

| 原子项 | 本次默认行为 |
| --- | --- |
| 多行输入与失焦校验 | 每行独立输入，可添加一行或一次添加多行。最多30行，使用现有1–32位字母/数字规则；不静默丢弃非法字符 |
| 校验后自动留空行 | 成功后在上限内追加一个空行，保持现有输入节点和焦点，不整表重建 |
| 多条校验 | 一次校验全部待处理项，重复口令按规范化后的code识别，只处理第一行；缺少或无效类型不可安装 |
| 稳定行身份 | 每行独立ID和递增revision，不使用数组下标接收回复。输入A→B→A、删除/移动邻居、取消或卸载都使旧校验失效 |
| 混合类型 | UI依据服务器type/_serverType显示技能或插件；旧0.5检查不存在的kind可能误标类型。实际目的目录仍由默认宿主与包清单确定 |
| 显式顺序安装 | 只在点击“安装已校验项目”后对当前已校验集合逐项安装，不把后续新校验项偷偷加入队列；只发送code和预期kind，不回传旧entry作身份依据 |
| 部分失败与重试 | 明确失败保留原因并继续其它项；成功项不自动重试，失败项须重新校验，再显式安装。超时/断连/响应不完整视为待核对，停止后续队列，避免盲目重放 |
| 取消/换页 | 停止后续操作、切换社区页签、离开面板停止尚未发出的安装。当前请求可能已提交，不声称取消能撤销已发生的文件写入；在途结果仍按实际回执报告或到已安装列表核对 |
| 关闭与清理 | 离页关闭状态机，禁用旧控件，取消未完成校验的发布资格，迟到结果不能重绘或发送下一项。口令草稿不写永久浏览器存储 |
| 安装状态 | 保持默认安全安装器的原子落盘、同ID拒绝覆盖及强制停用；不自动授予权限或执行安装代码 |

原单口令UI还存在改输入后保留旧verified的问题；现在每次输入立即清除该行安装资格，不等blur或下次网络回复。按钮可用性由状态机驱动，不能由通用按钮finally重置覆盖容量或忙状态。

## 追加替换

默认`ui/panels/community/code-install-state.js`负责无DOM的行/校验/安装策略，`code-install-view.js`负责当前沙箱文档内的增量视图。`panel.js`仅适配原有RPC并将社区页签/离页通知交给它们。两个文件都可以通过既有ui.assets追加替换；后端仍由当前选中的market.client、console.routes和extensions.installZip消费路径执行。普通市场包不会因此得到可信启动组合权限。
