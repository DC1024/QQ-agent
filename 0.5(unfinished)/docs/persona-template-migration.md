# 人设模板与继承的择优迁移

默认`console.personaTemplates`控制器、`core.prompt.persona`策略及`panels/settings/persona-templates.js`界面均为实际消费的独立默认项，可以分别通过追加组件或UI资产替换。内核将本次所选`runtime.persona.text`快照传给控制台，模板与初始默认角色同源；不会用当前已编辑角色冒充出厂模板。显式空文本不回退资产，直接调用旧控制台注册函数且未提供文本时保留资产兼容。

GET模板不写配置。旧条目获得内容及重复序号派生的稳定ID，第一次成功变更在同一次配置保存中持久化所有幸存ID；新条目用随机ID。删除必须提交目标DTO的revision，旧下标ID、缺失或陈旧revision均409，不会指向删除前项后的相邻模板。删除模板继续保留当前角色，不恢复旧版强制重置角色的行为。

内置模板明确携带空customRules，切换时清除旧模板的附加规则，账号身份保持。界面保存失败保留名称/角色/规则草稿，关闭后的迟到请求不复活面板；旧列表回复不能撤销已接受的新条目，保存时继续输入的新名称也保留。

分会话策略只在`personaUnified===false`时采用，四个覆盖字段仍是角色、附加规则、系统覆盖和参与度。空白/非字符串文本继承全局，参与度只接受low/medium/high；账号名等身份不能被分会话条目替换。遗留bareID优先完整chatKey的规则保持，新增表单明确显示实际来源及共享影响。

211实际经过默认编排器、runner和system/user两处提示词，覆盖磁盘重读、同ID内容冲突、重复模板、配置rename失败、界面迟到/关闭/输入保留，以及控制器/策略/UI单文件追加替换和停用恢复。有头和无头最终各exit0；74原27项保持，31/37只将旧下标断言改为稳定ID和目标revision。详细矩阵与日志位于`.qa-local/persona-template-parity-211/report.md`。

## 分会话编辑及并发保存

独立默认`console.personaByChat`控制器和`settings/persona-by-chat.js`、`persona-by-chat-state.js`已接入。候选来源为白名单、已有聊天和已存映射的并集，孤立旧bareID仍可单独打开。界面预览调用所选`core.prompt.persona`；自定义策略的内部继承不能推断时明确标记，避免用默认策略的解释冒充其实际结果。

GET返回明确storageKey、来源守卫及逐字段版本。PUT只提交四个允许字段中实际修改的字段及各自旧版本，不同字段合并；同字段冲突或来源切换409，写入前不改变配置。提交调用一次config.update并保留其它映射及未知元数据；成功回执只更新本次字段，保存中继续输入的草稿保持。冲突后需明确采纳服务端值或保留草稿再提交，没有静默改写基线。

旧共享条目明确说明同时影响同号群聊和私聊，提交需shared:true。清空其四字段时保留空对象，避免隐藏的完整chatKey条目突然恢复；完整chatKey空条目仅在无其它元数据时移除。模板应用只改变本地角色/规则草稿，嵌套创建模板不擅自改全局角色。账号身份不可由此编辑。

215最终有头、无头各16组通过；211包含新的设置集成回归。证据位于`.qa-local/persona-by-chat-215-formal/report.md`。首启导航见[startup-navigation.md](startup-navigation.md)。跨页未保存表单的持久草稿仍未提供。单批定向通过不等于全部0.4功能迁移或整轮最终回归完成。
