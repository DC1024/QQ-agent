# 暖黑黄绿与骨白橄榄绿主题

记录日期：2026-10-13。此次重做之前的简约 UI 已保存在 `.qa-local/backups/minimal-ui-20261013-043341-5e701811`；备份属于本地工作区，未打包为安装程序。

## 配色与设计说明

主题以暖黑底色、骨白文字和荧光黄绿强调构成暗色基准；浅色基准使用骨白底色、橄榄绿强调和浅灰分区。布局与交互围绕状态清楚、操作连续、反馈及时组织。

窄导航、几何图标、编号列表与详情区域使用一致的灰阶分区；局部黄绿强调帮助定位当前选择和主要操作。透明层、细分隔线与适量留白用于区分控件和正文。

相邻灰阶区分导航、状态、正文与详情，薄线和适量高亮帮助识别操作。下文颜色、尺寸和动效时长均为本项目自己的主题令牌。

共享入口是 `ui/panels/design-system.css`，`common.css` 引入它并提供面板结构。九个内置面板使用同一套控件规则，各自的样式只表达页面布局。设置中的组件预览展示按钮、字段、状态、字体和图标；示例交互不保存配置，也不调用业务接口。卡片角标依赖卡片自己的定位包含块；取消窄屏 sticky 时保留 `position: relative`，避免角标越过页面边界。

`theme.js` 保留亮色、暗色、自定义方案、迁移、重命名、删除和背景裁剪协议。颜色切换更新 CSS 变量；不会重建导航或清空业务状态。`readableAccentInk()` 只修正绘制用的文字色，不覆盖用户保存的配色。

批量换色期间，`holdThemeColorTransitions()` 短时将共享控件的颜色过渡时长设为0，让新颜色直接生效；两次实际送达的有限帧回调后恢复原令牌。它保留 transform/opacity 通道，不添加整页闪烁、遮罩或淡入，后台、减少动效偏好和 pagehide 会收尾。设置的 `theme-preview.js` 把下一次帧回调前的连续预览合并为最新方案；每个字段仍立即记入原 FormState，保存队列不变，change/离开会发起最终预览。离开不等待预览 RPC，不增加导航等待。这里的“一帧/两帧”是回调次数，不能保证浏览器低频调度时的固定毫秒延迟。

## 图标体系

`icons.js` 提供统一的 `createIcon(name, { size })`。2026-10-13整套重设计及就绪状态扩展后，39款导航、操作、品牌、存档与状态图形均为原创SVG；描边与实心部件均为 `currentColor`。使用24单位画布、1.65单位描边、45°切角、开放轨道与少量实心端块，避免所有入口都套相同方框。导航保持28px，小控件保持其调用尺寸。名称经过白名单匹配，未知扩展使用通用面板图标，不把插件元信息当作 SVG 代码执行。图标作为装饰使用 `aria-hidden`，按钮与链接保留文字名称。

品牌使用开口定位框与菱形核心，存档使用接收托盘与数据归入箭头；空状态使用同形的本地 `assets/endfield/archive.svg` alpha遮罩，颜色仍来自currentColor。当前UI不再引用此前两款PNG；原图和 `generation-prompts.json` 保留作历史资产，最简UI备份不受影响。图形不替代应用名称、文字操作或业务状态，不使用官方标志。

`createIcon()` 在当前文档懒安装一次 `icon-motion.js`。按用户澄清，“焦点”指对应页签被选中。宿主当前页面的 `aria-current="page"`、页签的 `aria-selected="true"` 或明确的 `data-icon-active="true"` 驱动语义动作，只有选中项持续播放；hover和普通键盘焦点不启动图标动画。鼠标移开、进入iframe输入或窗口失焦不会取消仍可见的当前选中项；切换选择后旧项静止。文档后台、减少动效、禁用、隐藏、移除及卸载会暂停或取消，恢复可见后从保留的DOM选择状态继续。效果由浏览器动画引擎驱动，JS没有逐帧任务或循环定时器，每个文档共用清理observer。部件以 `data-icon-role` 选择，避免改变路径顺序后动画落到错误轮廓上。本节为现行约定，下文此前图形、PNG、有限一次动画及hover循环记录保留为历史证据。

## 动效与生命周期

共享 `motion.js` 使用短时 opacity/transform 动画。首屏、列表追加和显露内容每批最多 12 项；聊天移动既有消息节点时，只为新增身份执行入口动画。全替换式轮询不会重复播放整张列表。CSS 处理悬停、按压和焦点状态，JS 处理弹窗、details、内容显露、详情选择及消息追加。

模块没有常驻 `requestAnimationFrame`、循环定时器或永久 `will-change`。系统减少动效偏好、页面转入后台、节点移除以及页面卸载会取消在途动画；关闭的 dialog 和隐藏内容保持隐藏。结束后不保留动画样式，关闭和提交结果不被拦截。实际流畅度与帧率应由目标设备上的验证记录确认，不能从动效实现方式直接推出。

临时弹窗另使用纯 DOM 的 `dialog-lifecycle.js`：`installDisposableDialog()` 只包装所传实例的 close，不修改原生 prototype，不导入面板客户端、存储或宿主 API。显式关闭和 ESC 在同一执行栈完成移除与 `onClosed`，保留原生 returnValue、已被阻止的 cancel 和直接原生 close 事件回退；重复关闭、dispose及旧事件只清理一次。9处通用临时弹窗接入此规则，宿主令牌管理和诊断再通过回调释放自己的状态。令牌两个输入同步清零，忙态关闭禁用仍保留；诊断关闭同步 abort 三个 renderer 请求信号，旧桌面结果不能更新新实例。静态 app confirm、public-captcha，以及业务发送、保存与授权协议不因此改变；反馈/金句的发布和媒体生命周期仍由各自专用清理负责。

## 插件化与隐私边界

插件仍在自己的 `ui/` 目录提供 HTML、JS、CSS 和图片，通过已授权的 `ctx.ui.panel.register()` 注册新面板。它可以自愿引用 `/panels/common.css`、`theme.js`、`icons.js` 与 `motion.js`；宿主不会向未知 iframe 注入全局样式或脚本。未接入共享体系的旧插件继续使用自己的界面。

宿主在面板 ready 后发送当前主题，随后发送主题变更事件。用户面板只收到 `publicPanelTheme()` 的视觉 DTO：明确列出的合法色值与布局字段，排除背景图片地址、私有方案名称、密钥、宿主配置与未知对象。面板通过 `panel-client.js` 转发的文档内 `qq-theme` 事件消费颜色，并且只在自己的文档写入令牌。

用户 RPC 仍限 `ctx.call`、`ctx.getConfig`、`ctx.notify`；用户面板不能调用 `theme.apply`、普通宿主 API 或修改全局配置。iframe 保持 `sandbox="allow-scripts"`，协议保留 source、origin、面板 ID、一次性 nonce 和加载代际校验。共享视觉事件不开放全局日志、聊天、会话或其他插件的数据。

完整接入示例和公共字段说明见 [插件 SDK](plugin-sdk.md)。

### 动效性能的实测范围

帧探针仅在 QA 副本中安装，生产源没有探针。它在首屏或点击后采集约 1500ms 的 rAF 间隔；“活动阶段”指相邻两帧至少一帧存在运行中的动画。这是页面回调节奏采样，没有使用 GPU 呈现追踪，也不能由平均帧率推断所有瞬间都满帧。
