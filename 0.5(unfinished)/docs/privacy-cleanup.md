# 当前项目隐私清理（2026-10-23）

本次按用户要求清理当前文件与本地运行数据，保留 Git 提交历史。

- 移除本地聊天、成员记忆、会话、媒体、日志、浏览器登录状态、个人配置备份及旧构建/验收副本；不另存含隐私的备份。
