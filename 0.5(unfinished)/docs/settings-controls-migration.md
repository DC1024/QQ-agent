# 设置控件的择优迁移

221恢复自然语言关键词的逐行语法，独立`settings/keyword-editor.js`保留短语内部空格及逗号。普通QQ号码/域名列表仍沿用各自语法，避免为一个字段改变其它控件。真实保存、磁盘重读及默认ingest→orchestrator→runner验证了2/3档完整短语匹配，编辑后不会意外扩大关键词响应范围。

独立`settings/list-choice.js`只在读取到有效非空QQ列表后开放名单提交。加载中、空返回、坏DTO或读取失败不覆盖现有名单；读取未返回的已有号码仍可见且默认保留。用户明确全取消时，按钮及影响说明区分空表全放行/全拒绝。提交成功回执后关闭，失败留窗、勾选和主表单草稿可重试；保存期间继续勾选不会被旧回执关闭，失败后改回原值也能撤销失败暂存。

分群编辑先用白名单与已有分群映射建立可编辑候选，再异步补充在线群名/新候选。群名读取失败不阻断按群号编辑；迟到名字不重建已编辑输入。提交只整理本次变化字段，保留邻居及未知元数据。现有POST/config没有新增服务端逐字段CAS，因此不承诺解决多窗口修改同字段或同一映射的竞争。
