# 默认首启导航

`ui/shell/startup-navigation.js`是实际宿主消费的独立默认策略，可通过追加一个`ui.assets`文件替换。没有覆盖层时，仅在首个页面确为默认首页、用户尚未手动导航且配置读取成功时考虑引导：HTTP(S)模型地址或模型名缺失进入models；模型就绪但没有有效白名单且未允许空表放行进入access。已经配置则照常打开默认首页。

宿主共用首个状态读取的配置请求，不为引导另起轮询。等待默认最多800ms，策略错误、读取失败、超时、自定义首面板或无合适设置页面均回到普通首页。迟到结果不抢导航；手动导航和销毁中断等待，销毁后不重挂iframe或重开SSE。配置变更用代际守卫拒绝旧预取和旧运行快照；清单首次失败后恢复也只采用当时有效配置。

后台`panel-metadata.js`验证所选页面入口及声明启动脚本的来源。`kind:bundled`或名叫settings不足以继承默认能力：受信任追加层整页替换后须明确声明navigation.role/sections，默认首页也需真实默认来源。设置挂载仅向有对应声明的页面传入models/access分区；普通市场页面不能通过相同ID获得此身份。摘要和内存快照合同见[记忆迁移](memory-view-migration.md)。
