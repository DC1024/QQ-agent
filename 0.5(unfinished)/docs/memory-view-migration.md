## 按成员保存备注

新增默认`console/member-notes.js`控制器，由默认console.routes实际装配。`GET /api/member-notes/:uid`返回`{note}`；`PUT`只接收`{note,expected?}`，只修改该UID，空字符串删除。同步读取当前映射、比较可选旧值并提交配置，期间无await。两个成员的修改合并，同成员陈旧旧值返回409，不覆盖新值。配置保存失败不发布成功事件；同值保存不重复落盘/发事件。仅默认记忆面板增加这两个精确API声明，普通插件不因此获得配置或宿主令牌。
